A model in the page can be held to a grammar: `providerOptions: { kanzo: { grammar } }`, an EBNF string, reaches WebLLM's engine and every token `localModel` writes is one the grammar allows. A Task declares `grammar(input, context)` in place of `output` when its artefact is text in a language — a Fossil mapping — and its oracles check the text as any artefact; `LocalCallOptions` types the option.
