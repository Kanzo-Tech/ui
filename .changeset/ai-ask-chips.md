`AskChips` draws what an Ask answer was read as — what is counted, what a chart is by, each condition — each a chip that opens the values it can hold instead, computed and checked by Ask's oracles. Taking one sends `askEdit(spec)`, which the chat asks as it is, with no model call. An `answer` part's output now carries its spec (`AskOutput`). `@kanzo-tech/ai/task` exports `verify(task, value, input)`, the oracles' verdict on a value no model wrote.
