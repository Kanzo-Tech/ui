## Usage

```tsx
import { Button, DownloadTrigger } from "@kanzo-tech/ui";
```

`DownloadTrigger` wraps Ark's `download-trigger` machine: give it the `data` (a string, `Blob`,
`File`, or a function/promise returning one), a `fileName` and a `mimeType`, and it builds an
object URL and clicks it for you. It renders a `<button>`, so compose our `Button` through
`asChild` rather than restyling it:

```tsx
<DownloadTrigger
  asChild
  data={csv}
  fileName="open-contracts.csv"
  mimeType="text/csv"
>
  <Button variant="outline">Export the board</Button>
</DownloadTrigger>
```

`data` may defer: pass `() => fetch(url).then((r) => r.blob())` to resolve the content only when
the user clicks.
