Four layers, each with a different job: **simples** are single-purpose elements, **composites**
assemble simples into something that still fits inside a page, **layouts** scaffold the page
itself, and **blocks** are whole screens showing how the rest is meant to go together.

This grid is generated from the page tree, so it cannot fall behind the docs: a component has a
card here exactly when it has a page.
