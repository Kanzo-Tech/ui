## Usage

```tsx
import { SidebarNav } from "@kanzo-tech/ui";
```

```tsx
<SidebarContent>
  <SidebarNav items={items} label="Platform" />
</SidebarContent>
```

It must be rendered inside a [`SidebarProvider`](/docs/sidebar) — it reads the
sidebar's state to close the mobile drawer when an entry is followed.

An item with `items` becomes a collapsible group, open by default when it is `isActive`;
an item with `href` is a leaf. Navigation goes through the injected `linkComponent`, so the
design system never imports a router.

## Anatomy

```text
SidebarNav
└── SidebarGroup
    ├── SidebarGroupLabel        (label)
    └── SidebarMenu
        └── SidebarMenuItem
            ├── SidebarMenuButton        (leaf)
            └── Collapsible              (group)
                └── SidebarMenuSub
                    └── SidebarMenuSubItem
                        └── SidebarMenuSubButton
```
