<Callout type="info">
**Breadcrumb vs [Breadcrumbs](/docs/navigation/breadcrumbs):** the plural one is built on this
one. `Breadcrumb*` is the compound vocabulary — you write each item, separator and ellipsis, and
you can put anything in them.

`Breadcrumbs` takes an `items` array and renders the same parts for you, including the collapse
when the trail is long. Use it unless you need to control what an individual crumb contains.
</Callout>

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@kanzo-tech/ui";
```

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/board">The board</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Q-1058</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

The last crumb is a `BreadcrumbPage`, not a link: it carries `aria-current="page"` and is not
navigable, because it is the page you are already on.

## Anatomy

```text
<Breadcrumb>            ← <nav aria-label="Breadcrumb">
  <BreadcrumbList>      ← <ol>
    <BreadcrumbItem>
      <BreadcrumbLink /> | <BreadcrumbPage /> | <BreadcrumbEllipsis />
    <BreadcrumbSeparator />
```

## Custom separator and ellipsis

Separators are `aria-hidden` presentation, so swapping the glyph is purely visual. Use
`BreadcrumbEllipsis` to collapse a deep middle section.

## API Reference

### Breadcrumb

| Prop | Type | Default |
| --- | --- | --- |
| `aria-label` | `string` | `"Breadcrumb"` |

### BreadcrumbSeparator

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `ReactNode` | `<ChevronRightIcon />` |

Each part extends its `ark.*` element (`ark.nav`, `ark.ol`, `ark.li`, `ark.a`, `ark.span`), so
`href`, `ref` and the rest pass through. For a data-driven crumb trail with a router link,
use the `Breadcrumbs` composite instead.
