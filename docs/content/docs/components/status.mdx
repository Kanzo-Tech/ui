## Usage

```tsx
import { Status } from "@kanzo-tech/ui";
```

```tsx
<Status variant="success" />
```

`Status` is `aria-hidden` — a bare colour is not an accessible state. Always pair it with the
text it decorates, as in the example above.

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "success" \| "info" \| "warning" \| "destructive"` | `"default"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |

Extends `React.ComponentProps<typeof ark.span>`. `statusVariants` is exported if you need the
same treatment on another element.
