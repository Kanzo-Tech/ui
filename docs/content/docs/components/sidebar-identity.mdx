## Usage

```tsx
import { SidebarIdentity } from "@kanzo-tech/ui";
```

```tsx
<SidebarIdentity data={{ label: "Kanzo", description: "Owner", icon: <BoxesIcon /> }} />
```

This is the block [`SidebarUser`](/docs/components/sidebar-user) and
[`InstanceSwitcher`](/docs/components/instance-switcher) both render in their trigger and in
their menu header — extracted so the two cannot drift apart. Reach for it directly when you
build a third switcher of your own.

`icon` swaps the round avatar for a square tile: round reads as a person, square as a
workspace or org.

## Collapsing

`responsive` gates the `group-data-[collapsible=icon]` variants — the text column and the gap
collapse away and the avatar grows to fill the 32px square. Leave it off for the portaled menu
header, which is never collapsed. `collapsed` tells the avatar which semantic size to use, so
badges and icons inside it stay correctly scaled.
