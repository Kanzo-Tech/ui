## Usage

```tsx
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
  useFilter,
  useListCollection,
} from "@kanzo-tech/ui";
```

```tsx
<Combobox
  collection={collection}
  onInputValueChange={(details) => filter(details.inputValue)}
>
  <ComboboxInput placeholder="Search datasets…" />
  <ComboboxContent>{/* items */}</ComboboxContent>
</Combobox>
```

Filtering is yours to own — the machine never mutates the collection. `useListCollection`
holds the items and gives you a `filter(inputValue)`, and `useFilter` supplies a locale-aware
`contains` so accents and case do not block a match.

## Anatomy

```text
Combobox
├── ComboboxInput          (wraps ComboboxControl + InputGroup)
│   ├── ComboboxTrigger
│   └── ComboboxClear
└── ComboboxContent
    ├── ComboboxEmpty
    ├── ComboboxList
    └── ComboboxGroup
        ├── ComboboxGroupLabel
        └── ComboboxItem
```

## API Reference

### ComboboxInput

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `showTrigger` | `boolean` | `true` |
| `showClear` | `boolean` | `false` |

Renders `ComboboxControl` and an `InputGroup` around `Combobox.Input`. Use
`ComboboxFieldInput` instead when you need the bare input inside your own control.

### ComboboxItem

| Prop | Type | Default |
| --- | --- | --- |
| `showIndicator` | `boolean` | `true` |

### ComboboxGroup

| Prop | Type | Default |
| --- | --- | --- |
| `heading` | `string \| React.ReactNode` | — |

`Combobox` defaults `openOnClick`, `lazyMount` and `unmountOnExit` to `true`.
