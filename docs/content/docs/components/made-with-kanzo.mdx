## Usage

```tsx
import { MadeWithKanzo } from "@kanzo-tech/ui";
```

```tsx
<MadeWithKanzo href="https://kanzo.tech" />
```

The heart carries `role="img"` and an accessible name, so the line reads as "Made with love at
Kanzo" rather than dropping the word a sighted reader gets from the glyph.

## Link and brand

`by` renames the brand and `href` makes it a link — the component is generic enough to sign
someone else's product.
