## Usage

```tsx
import { PageShell } from "@kanzo-tech/ui";
```

```tsx
<PageShell>
  <PageShell.Header title="Dashboard" description="…" actions={<Button>New</Button>} />
  <PageShell.Content>…</PageShell.Content>
  <PageShell.Footer>…</PageShell.Footer>
</PageShell>
```

`Content` is the only region that scrolls, so the header and footer stay put while a long
table moves under them. That only works if the shell has a resolved height — give the flex
parent one (a `SidebarInset` already does).

`Content` renders a `<section>`, not a `<main>`: PageShell is nested by construction inside an
app shell that already owns the page's single `<main>` landmark, and two of them make "skip to
main content" ambiguous.
