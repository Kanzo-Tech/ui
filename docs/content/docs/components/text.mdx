## Usage

```tsx
import { Text } from "@kanzo-tech/ui";
```

```tsx
<Text as="p" variant="muted">
  1,204 records.
</Text>
```

`Text` covers typography only. For layout — rows, gaps, spacing — use Tailwind utilities
directly; the design system ships no `Flex` / `Box` / `Grid`.

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `as` | `React.ElementType` | `"span"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `"sm"` |
| `weight` | `"normal" \| "medium" \| "semibold" \| "bold"` | — |
| `variant` | `"default" \| "muted" \| "primary" \| "destructive"` | `"default"` |
| `align` | `"start" \| "center" \| "end"` | — |
| `truncate` | `boolean` | — |

Extends `React.ComponentProps<"span">`. `textRecipe` is exported for composing the same scale
elsewhere.
