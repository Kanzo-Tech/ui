## Usage

```tsx
import { SectionHeader } from "@kanzo-tech/ui";
```

```tsx
<SectionHeader title="Connections" description="Sources this workspace reads from." />
```

## Actions

`actions` is right-aligned and never wraps under the title, so a long description cannot push
the controls out of reach.

<ComponentPreview componentName="section-header" fileName="example-actions" />

## Heading level

It renders a real `<header>` landmark with a real heading. `headingLevel` sets which one, so
the header slots into the surrounding document outline instead of asserting `h2` everywhere.
`bordered` draws the separator underneath.
