## Usage

```tsx
import { StatCard } from "@kanzo-tech/ui";
```

```tsx
<StatCard label="Connections" value="4" description="connections configured" />
```

## Status

`status` tints the icon disc from the status tokens, so a theme change re-skins the whole
dashboard row without touching a call site.

<ComponentPreview componentName="stat-card" fileName="example-status" />

## Loading

`loading` is explicit — the card never infers a pending state from an undefined `value`. The
skeleton is sized to the rendered figure, so the tile does not jump when the number arrives.

<ComponentPreview componentName="stat-card" fileName="example-loading" />

## As a link

With `href` the whole card becomes one link target — a single tab stop, which is what a tile
should be. Without it the card is inert. Pass `linkComponent` to route through your router.
