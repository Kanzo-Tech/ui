## Usage

```tsx
import { NumberField, TextField } from "@kanzo-tech/ui";
```

```tsx
<TextField iconStart={<SearchIcon />} placeholder="Search datasets" />
```

`TextField` is [Input Group](/docs/simples/input-group) with the composition already done:
adornments go in `iconStart` / `iconEnd` instead of `InputGroupAddon` children. It inherits
that chrome rather than restating it, so the border, focus ring, size scale and invalid
styling cannot drift from the rest of the form controls.

`className` lands on the input; `rootClassName` lands on the group, which is where the width
and border live.

## Number field

`NumberField` is the same facade locked to numeric entry — `type="number"` plus
`inputMode="decimal"`, so mobile keyboards open on digits.

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `invalid` | `boolean` | — |
| `iconStart` | `React.ReactNode` | — |
| `iconEnd` | `React.ReactNode` | — |
| `rootClassName` | `string` | — |
| `data-slot` | `string` | `"text-field"` |

Extends `InputProps` (minus `size`), so `ref` and every native input prop pass through.
`NumberField` takes the same props minus `type`.
