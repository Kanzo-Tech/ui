title: Coming Soon

## Usage

```tsx
import { ComingSoon } from "@kanzo-tech/ui";
```

```tsx
<ComingSoon>
  <Button variant="outline">Export to Parquet</Button>
</ComingSoon>
```

This is a decorator, not a label: it wraps the content, dims it and marks it `inert`, so an
unavailable control can stay visible — still telling the user the feature exists — without
being operable. `inert` rather than `aria-hidden` because the content should remain readable,
just unreachable. Reach for a plain `Badge` when you only want to annotate something that
still works.

## Placement

The corner badge deliberately overhangs the wrapper so it reads as a tag pinned *on* the
thing. That overhang is clipped by any ancestor that scrolls or hides overflow — leave the
wrapper room, or use `placement="inline"`.
