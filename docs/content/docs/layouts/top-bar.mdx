## Usage

```tsx
import {
  TopBar,
  TopBarUtility,
  TopBarMain,
  TopBarTitleGroup,
  TopBarTitle,
  TopBarSubtitle,
  TopBarActions,
} from "@kanzo-tech/ui";
```

```tsx
<TopBar>
  <TopBarUtility>{/* pickers, attribution, breadcrumbs */}</TopBarUtility>
  <TopBarMain>
    <TopBarTitleGroup>
      <TopBarTitle>Catalog</TopBarTitle>
      <TopBarSubtitle>12 datasets</TopBarSubtitle>
    </TopBarTitleGroup>
    <TopBarActions>
      <Button>New dataset</Button>
    </TopBarActions>
  </TopBarMain>
</TopBar>
```

`TopBarUtility` is a low-key strip above the title bar. It is optional — omit it and the title
bar is the whole chrome.

`TopBar` is pure layout with no domain of its own, which is why it is a `<header>` and nothing
more. Drop it into [`AppShell`](/docs/layouts/app-shell) as its first child.

## Anatomy

```text
TopBar
├── TopBarUtility
└── TopBarMain
    ├── TopBarTitleGroup
    │   ├── TopBarTitle
    │   └── TopBarSubtitle
    └── TopBarActions
```

`TopBarTitle` renders an `<h2>`: the top bar names the view, not the document — the page's
`<h1>` lives in the content, usually a [`PageShellTitle`](/docs/composites/page-shell).

## API Reference

Every part takes the props of the element it renders. None of them carry options of their own.

| Part | Element |
| --- | --- |
| `TopBar` | `header` |
| `TopBarUtility` | `div` |
| `TopBarMain` | `div` |
| `TopBarTitleGroup` | `div` |
| `TopBarTitle` | `h2` |
| `TopBarSubtitle` | `span` |
| `TopBarActions` | `div` |
