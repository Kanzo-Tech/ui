**This page is a plan, and none of it is built.** It indexes decisions the owner took on 13 October

fossil's corpus, and keasy's use of both. Each decision is argued on the page it belongs to, with

The library was right where it adopted directly — the parts that follow shadcn and Ark, the chat
parts that follow AI Elements, Mosaic's crossfilter, the navigation guard. What the review found was
in three places: **the seams**, where one idea arrived in two or three shapes and each package
translated it its own way; **the guesses**, where Ask and a field's statistics derived from a
column's name or a threshold what the corpus states exactly; and **the remains** of earlier designs —
an answer tool's schema, a tool call made up to draw a card, aliases and re-exports that give one
thing two doors. Most of the work is applying two rules the repository already has: one way per
idea, and the reference wins.

## The principles every item comes from

1. **One door per idea.** One concept, one type, one name, one place to import it from.
2. **A field's facts come from the data, not its name.** What it is, from the manifest; what it
   holds, from fossil's profile.
3. **A standard where there is one.** Labels are `rdfs:label`; a language is BCP 47; lists and
   numbers are `Intl`'s; a path is Malloy's; a filter on another relation is a semi-join; an error
   on the wire is RFC 9457. Where there is none, the page says so and takes the least.
4. **One read per datum.** The dashboard, Ask, the card and the assistant read through one door and
   share its cache.
5. **Every word translatable, the same way everywhere:** `translations`.
6. **A product's call site admits a name to the barrel.** What has none leaves for a docs example.

updates the usage pages it changes; the *Breaking* lists on the pages above are those changesets'

kept chat before the joins land, say. Then that row moves up with what it waits on, and nothing
else moves.
