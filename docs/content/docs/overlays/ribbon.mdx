## Usage

```tsx
import { Ribbon } from "@kanzo-tech/ui";
```

```tsx
<Ribbon label="Beta" variant="info">
  <Button variant="outline">Export the ledger</Button>
</Ribbon>
```

Modelled on Ant Design's `Badge.Ribbon`: it wraps a region and pins a status badge on it. By
default it only annotates — the content stays live — so it fits "Beta", "New" or "Pro" just as
well as "Coming soon". The `label` is whatever state you are flagging.

## Gating

Pass `disabled` to gate the region as well as label it: the content is dimmed and made `inert`,
so an unavailable feature stays visible — still telling the user it exists — without being
operable. `inert` rather than `aria-hidden` keeps it readable, just unreachable. Reach for a
plain `Badge` when the content still works and you only want to tag it.

## Placement

The corner badge deliberately overhangs the wrapper so it reads as a tag pinned *on* the thing.
That overhang is clipped by any ancestor that scrolls or hides overflow — leave the wrapper
room, or use `placement="inline"`, which puts the badge in the flow at the trailing edge so it
takes its own space instead of covering the content.
