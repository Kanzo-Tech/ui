<Callout type="info">
**A metric card is a composition, not a library component.** A dashboard tile is a
[Card](/docs/data-display/card) with a status tint, a [Skeleton](/docs/data-display/status)-swapping
figure and an optional link — no new behaviour, so per the design system it lives as an
arrangement you copy into your app, not an import from `@kanzo-tech/ui`. The snippet below is the
whole thing; the examples on this page render that exact composition.
</Callout>

## Compose it from Card

```tsx
import { Card, cn, DefaultLink, type LinkComponent, Skeleton } from "@kanzo-tech/ui";

export function MetricCard({ status = "neutral", href, className, ...rest }) {
  return (
    <Card
      className={cn("flex min-h-32 flex-col gap-0 px-5 py-4 shadow-none", className)}
      data-status={status}
      {...rest}
    />
  );
}
// …plus small MetricCardHeader / Icon / Label / Value / Description parts — see the copy below.
```

```tsx
<MetricCard>
  <MetricCardHeader>
    <MetricCardIcon><DatabaseIcon /></MetricCardIcon>
    <MetricCardLabel>Connections</MetricCardLabel>
  </MetricCardHeader>
  <MetricCardValue>4</MetricCardValue>
  <MetricCardDescription>connections configured</MetricCardDescription>
</MetricCard>
```

## Anatomy

```text
MetricCard
├── MetricCardHeader
│   ├── MetricCardIcon
│   └── MetricCardLabel
├── MetricCardValue
└── MetricCardDescription
```

## Status

`status` stays a prop on the root: it is state, not content, and it has to be read by the icon
disc, which picks the tint off the root's `data-status` rather than through context — so the
part needs no client boundary. A theme change re-skins the whole dashboard row without
touching a call site.

## Loading

`loading` sits on `MetricCardValue` and `MetricCardDescription` — the two parts that actually swap
for a skeleton. The label and icon are known before the figure is, so they keep rendering. The
skeleton is sized to the rendered text, so the tile does not jump when the number arrives.

## As a link

With `href` the whole card becomes one link target — a single tab stop, which is what a tile
should be. Without it the card is inert. Pass `linkComponent` to route through your router.

## API Reference

### MetricCard

Renders a `Card` (`div`); takes its props.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"neutral" \| "success" \| "warning" \| "danger"` | `"neutral"` |
| `href` | `string` | — |
| `linkComponent` | `LinkComponent` | `DefaultLink` |

### MetricCardValue / MetricCardDescription

`MetricCardValue` renders a `div`, `MetricCardDescription` a `p`.

| Prop | Type | Default |
| --- | --- | --- |
| `loading` | `boolean` | `false` |

### Other parts

`MetricCardHeader` and `MetricCardIcon` render a `div` and `MetricCardLabel` a `span`; each takes
that element's props and nothing more.
