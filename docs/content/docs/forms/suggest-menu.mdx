## Usage

```tsx
import { SuggestMenu } from "@kanzo-tech/ui";
```

```tsx
<SuggestMenu suggest={suggest} existing={keywords} onPick={add} />
```

`suggest` is a plain `(signal?) => AsyncIterable<Suggestion>`, so the component is
source-agnostic: a real call site yields straight from a streaming model response, a test
yields from an array.

Three rows stay on screen. Dismissing one pulls another from the stream to refill the window,
so there is always a full set to choose from rather than a list that shrinks as you reject it.
Suggestions matching `existing` — or each other, case-insensitively — are dropped before they
are ever shown.

The stream is fetched once per open-cycle and cached across reopen, so browsing away and back
does not re-bill the model. Closing the popover mid-load aborts the in-flight request through
the `AbortSignal` and refetches fresh next time.
