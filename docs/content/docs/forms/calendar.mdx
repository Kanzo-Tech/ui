## Usage

```tsx
import {
  Calendar,
  CalendarTable,
  CalendarTableDays,
  CalendarView,
  CalendarViewControl,
  CalendarWeekDays,
} from "@kanzo-tech/ui";
```

`Calendar` is Ark's DatePicker with `inline` fixed on, so the grid is always visible and
there is no trigger or popover. It is the same machine the
[Date Picker](/docs/forms/date-picker) uses, which is why the parts are shared: the grid
is a real `role="grid"` with roving tabindex, arrow-key navigation and month/year quick-nav.

`CalendarTableDays` and `CalendarWeekDays` read the weeks and weekday names off the machine,
so a locale change re-flows the grid without any work on your side.

## API Reference

### CalendarWeekDays

| Prop | Type | Default |
| --- | --- | --- |
| `format` | `"narrow" \| "short" \| "long"` | `"narrow"` |

### CalendarTableNextMonth

| Prop | Type | Default |
| --- | --- | --- |
| `months` | `number` | `1` |

`Calendar` extends `DatePicker.Root` from Ark, so `value`, `defaultValue`, `onValueChange`,
`selectionMode`, `numOfMonths`, `min`, `max`, `locale`, `startOfWeek`, `fixedWeeks`,
`isDateUnavailable`, `disabled` and `readOnly` pass through. `lazyMount` and `unmountOnExit`
default to `true`.
