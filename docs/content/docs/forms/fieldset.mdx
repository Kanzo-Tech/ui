## Usage

```tsx
import {
  Fieldset,
  FieldsetErrorText,
  FieldsetHelperText,
  FieldsetLegend,
} from "@kanzo-tech/ui";
```

```tsx
<Fieldset disabled>
  <FieldsetLegend>Billing address</FieldsetLegend>
  <Field>
    <FieldLabel>Street</FieldLabel>
    <TextField />
  </Field>
  <FieldsetErrorText>Address is incomplete.</FieldsetErrorText>
</Fieldset>
```

`Fieldset` renders a real `fieldset`/`legend`, so a group of related fields is announced as a
group. `disabled` and `invalid` on the root cascade to every `Field` inside it — one state for
the whole set.

## Anatomy

```text
Fieldset
├── FieldsetLegend
├── Field
│   └── …
├── FieldsetHelperText
└── FieldsetErrorText
```

## API

### Fieldset

Extends `Fieldset.Root` from Ark, so `disabled` and `invalid` pass through and cascade to the
fields inside.

### FieldsetLegend

Renders the `legend`, styled as a section label.

### FieldsetHelperText

Muted supporting text for the group.

### FieldsetErrorText

Destructive message for the group; renders while the fieldset is `invalid`.
