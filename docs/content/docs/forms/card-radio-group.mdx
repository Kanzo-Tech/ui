## Usage

```tsx
import { CardRadioGroup } from "@kanzo-tech/ui";
```

```tsx
<CardRadioGroup
  defaultValue="openai"
  options={[
    { value: "openai", label: "OpenAI", icon: <BotIcon /> },
    { value: "anthropic", label: "Anthropic", badge: "Recommended" },
  ]}
/>
```

Full radio semantics come from Ark — roving focus, arrow-key selection, hidden inputs — so
the card is purely how the option looks, never how it behaves.

Options are data, not children: an `options` array keeps the label, description, icon, badge
and preview of each choice in one place, which is what stops the same three-card layout from
being hand-rolled per screen. The icon is a node you pass, because a design system should not
pick your icon library.

## Horizontal

`showIndicator` puts the radio dot back on the card. Leave it off when the selected border
and fill already say enough.
