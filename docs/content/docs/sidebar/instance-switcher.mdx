## Usage

```tsx
import { InstanceSwitcher } from "@kanzo-tech/ui";
```

```tsx
<SidebarHeader>
  <InstanceSwitcher instances={instances} activeId={id} onSelect={setId} label="Workspaces" />
</SidebarHeader>
```

Render it inside a [`SidebarProvider`](/docs/simples/sidebar). It shares the collapse-aware
[`SidebarIdentity`](/docs/composites/sidebar-identity) trigger with
[`SidebarUser`](/docs/composites/sidebar-user), so the header and footer of a sidebar line up
pixel for pixel.

The switcher is controlled: it renders `activeId` and reports selections through `onSelect`,
so the product decides what switching actually does.

`actions` are extra entries below the list, separated from it — "Create workspace", "Manage
members". They take an `href` (routed through `linkComponent`) or an `onSelect`.

### Instance

| Prop | Type | Default |
| --- | --- | --- |
| `id` | `string` | — |
| `label` | `ReactNode` | — |
| `description` | `ReactNode` | — |
| `icon` | `ReactNode` | — |
| `avatarUrl` | `string` | — |

Without an `icon` or `avatarUrl` the tile falls back to the first two characters of `label`.
