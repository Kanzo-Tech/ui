## Usage

```tsx
import { Show } from "@kanzo-tech/ui";
```

`Show` renders `children` when `when` is truthy and `fallback` otherwise. It is a thin,
presentational helper — no hooks, no DOM of its own — that keeps a JSX tree flatter and more
scannable than a nested ternary:

```tsx
<Show fallback={<Spinner />} when={isReady}>
  <Content />
</Show>
```

Because it holds no state and touches no browser API, it stays server-renderable and carries no
`"use client"` boundary.
